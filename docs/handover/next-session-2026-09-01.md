## 7. 2026-09-01 추가 작업

PR #53의 예외 처리가 `국내주식`(붙여쓰기)만 통과시켜, `국내 주식 비중이 높은
공모펀드`처럼 **띄어 쓴 표기**는 여전히 차단되고 있었다. 원인은 세 곳에 같은
붙여쓰기 가정이 있었기 때문이다.

| 파일 | 대상 |
| --- | --- |
| `semantic_gate.py` | `_DIRECTION_METRIC_PATTERN`·`_NUMERIC_SORT_METRIC_PATTERN` |
| `semantic_gate.py` | `_UNAPPROVED_RELATION_FILTER` 왼쪽 경계 |
| `linker.py` | 정렬 패턴 8곳·숫자 조건 별칭 4곳 |

있으면 정규식이 `국내 ` 다음 위치부터 다시 스캔해 `주식 비중이 높은`에 걸린다.

개별 종목 질문은 그대로 막힌다. `삼성 주식 비중이 높은 ETF`, `주식 비중이 높은
공모펀드`는 여전히 차단됨을 테스트로 고정했다.
