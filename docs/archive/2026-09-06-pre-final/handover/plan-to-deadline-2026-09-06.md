## 1. 최우선 위험: 재배포

평가 서버는 아직 2026-08-31 이전 코드다. **재배포되지 않으면 오늘까지의 모든
수정이 채점에 보이지 않는다.** 2026-09-06 23:59 이후에는 코드·서버 변경이
실격 사유이므로, 재배포는 늦어도 09-05에 끝나야 한다.

- 담당: 임현호
- 필요한 것: PR #54 검토·병합 → NCP 재배포 → 공인 IP에서 `GET /answer` 재현
- 이 항목이 밀리면 다른 모든 작업의 가치가 0에 수렴한다

## 2. 확인된 사실

### 2.1 답변 불가 처리는 강점이다

공식 답변 불가 예시 3건을 실측했다. 주최 측은 "답변을 생성하면 감점"이라고
명시했는데, 셋 다 지어내지 않았다.

| 질문 | 결과 |
| --- | --- |
| 신용등급 AAAA인 채권 찾아줘 | `not_found` |
| Kimi 관련 투자 상품 있어? | `unsupported` |
| KODEX AI로봇 ETF 정보 알려줘 | `not_found` |

35문항 중 5문항이 이 유형이므로 14%를 안정적으로 확보하고 있다.

### 2.2 응답 5필드는 채워져 있다

`retrieved_context` 10,732자(citation JSON), `think_trace` 658자(구조화 실행
요약), `answer` 578자(상품·근거·기준일·원천·주의). 형식 미달은 없다.

### 2.3 사람이 읽는 문장에 흠이 있다

```
"품질 검증을 통과한 국내채권를 찾지 못했습니다"   ← 국내채권"을"
"AUM 25,834,235,404,500.00"                    ← 조 단위 표기 없음
```

`renderer.py:523`·`641`이 조사를 `가`·`를`로 고정한다. 상품군 라벨 중
`국내채권`만 받침이 있어 틀린다. 채점자가 직접 보는 문장이다.

## 6. 판단 근거

정렬 표현에서 25.7%가 실패하던 것을 2.1%로 낮췄다. 같은 방법을 아직 적용하지
않은 경로가 필터·집계·상세 조회다. 이것이 09-01~02의 우선순위인 이유는,
측정으로 크기를 확인할 수 있고 남에게 걸려 있지 않으며 실패가 곧 실점이기
때문이다.

09-03 이후를 제안서에 배정한 이유는 배점이 40점으로 API와 같은데 우리가 온전히
통제할 수 있고, 주최 측이 기대효과·확장성을 수상 결정 요소로 지목했기 때문이다.
