# 2026-08-06 오프라인 설명회 질문·답변 기록지

상태: 질문 확정·공식 답변 대기

목적: HyperCLOVA X 연결, 평가 API, 허용 모델과 데이터 사용 범위를 공식
답변으로 확정하고 설명회 이후 구현 결정을 추적

## 0. 기록 원칙

- 질문한 문장과 공식 답변을 가능한 한 그대로 기록
- 답변자, 답변 시각, 발표자료 페이지나 후속 공지 링크를 함께 기록
- 공식 답변과 팀의 해석·결정을 별도 칸에 작성
- 현장에서 불명확한 답변은 추측하지 않고 `후속 확인 필요`로 표시
- 공식 답변을 반영하기 전에는 HyperCLOVA X credential·실제 endpoint 연결 보류

## 5. 설명회 이후 실행 순서

1. 공식 답변 원문과 출처를 이 문서에 기록
2. 공식 사실과 팀 해석이 섞이지 않았는지 팀원 1명이 교차 확인
3. `project-baseline.md`의 모델·API·데이터 정책 갱신
4. HyperCLOVA X 실제 transport와 official response adapter 구현
5. 로컬 provider 없이 필수 회귀·fallback·오류 계약 검증
6. Backend 합류 후 FastAPI `/answer` route 연결
7. 제출 후보의 로컬 모델 구성 제거와 clean checkout 검수

설명회 답변이 없는 항목은 기존 보수적 정책을 유지하고 구현을 확장하지 않음
